# Лабораторна робота №3. Рекурсивні алгоритми

## Базові випадки рекурсивних функцій

1. **Завдання 1:** Базовим випадком є папка, яка не містить у собі жодних підпапок, через що цикл рекурсивного обходу вкладених директорій не виконується жодного разу.
2. **Завдання 2:** Базовим випадком є ситуація, коли ліва та права межі розгляду масиву збігаються (lo == hi), тобто в поточному підмасиві залишився лише один елемент.
3. **Завдання 3:** Базовим випадком є обнулення кількості залишкових сходинок (n == 0), що сигналізує про успішне досягнення вершини.

## Вивід трасування стеку викликів (Завдання 4)

```text
enter Count(0..3)
  enter Count(0..1)
    enter Count(0..0)
    exit Count(0..0) -> 0
    enter Count(1..1)
    exit Count(1..1) -> 1
  exit Count(0..1) -> 1
  enter Count(2..3)
    enter Count(2..2)
    exit Count(2..2) -> 0
    enter Count(3..3)
    exit Count(3..3) -> 1
  exit Count(2..3) -> 1
exit Count(0..3) -> 2
```

Рядки exit з'являються у зворотному порядку до enter через специфіку роботи структури даних стек (LIFO). Останній виклик функції, який було поміщено у стек останнім, завершується та виштовхується першим, передаючи обчислене значення назад на попередній рівень ієрархії.

## Відповіді на питання (Завдання 5)

1. **Який запис зрозуміліший для цієї задачі (Завдання 2) — рекурсивний чи циклічний, і чому?**
Для задачі підрахунку елементів у лінійному масиві циклічний запис є набагато простішим і зрозумілішим. Він напряму послідовно перебирає всі комірки пам'яті за один прохід, не перевантажуючи логіку поділом навпіл та не створюючи додаткових витрат ресурсів процесора й пам'яті на виклики функцій.

2. **Чому так само просто переписати циклом завдання 1 не вийде? Якої саме допоміжної структури даних для цього бракує?**
Для циклічного обходу деревоподібної структури папок звичайного лінійного циклу недостатньо, адже файлова система має невизначену заздалегідь глибину вкладеності. Для реалізації такого алгоритму без рекурсії довелося б вручну створювати й контролювати додаткову структуру даних — Стек (Stack) або Чергу (Queue), щоб самостійно зберігати шляхи до відкладених папок, які ще належить обробити. У рекурсивній версії цей стек операційна система веде за нас автоматично.
