## Завдання 3. Параметри агрегацій («стан, старт, крок»)

| Агрегація | Стан (Тип) | Старт (Початкове значення) | Крок (Операція) |
| :--- | :--- | :--- | :--- |
| **Сума** | `int` | `0` | `(acc, x) => acc + x` |
| **Добуток** | `long` | `1L` | `(acc, x) => acc * x` |
| **Максимум** | `int` | `int.MinValue` | `(acc, x) => x > acc ? x : acc` |
| **Конкатенація** | `string` | `""` | `(acc, w) => acc == "" ? w : acc + ", " + w` |

## Завдання 5. Вивід і пояснення трьох несподіванок (Захоплення змінних)

1. **Ситуація 1:** Виводить `False`. 
   * *Пояснення:* Лямбда захоплює змінну `threshold` за посиланням. Оскільки перед викликом значення змінилося на 1000, виконується перевірка `50 > 1000`.
2. **Ситуація 2:** Виводить `3 3 3`. 
   * *Пояснення:* Цикл `for` використовує одну змінну лічильника `i` для всіх ітерацій. Наприкінці циклу вона дорівнює 3, тому всі захоплені лямбди бачать фінальне значення `3`.
3. **Ситуація 3:** Виводить `0 1 2`. 
   * *Пояснення:* Починаючи з C# 5.0, цикл `foreach` створює нову локальну змінну на кожній ітерації, тому кожна лямбда захоплює своє власне унікальне значення.
