# Лабораторна робота №2

## Опис методів
* **Task1:** Рахує суму, середнє, мін, макс і нулі за один прохід циклу.
* **Task2:** Фільтрує елементи, які діляться на 5.
* **Task3:** Шукає найдовшу серію однакових чисел, що йдуть підряд.
* **Task4:** Робить циклічний зсув масиву вправо на 1 позицію.
* **Task5:** Обробляє матрицю 3 на 6 (суми рядків, максимуми в стовпцях).

## Завдання 6. Крайові випадки

| Вхід | Завдання | Очікувано | Отримано |
| :--- | :--- | :--- | :--- |
| порожній масив | 1-4 | Програма покаже повідомлення, що масив порожній, і не впаде через помилки індексів | Вивело «Масив порожній!» або повернуло порожній масив, нічого не зламалося |
| один елемент | 1-4 | Мін і макс будуть однакові (індекс 0), зсув вправо нічого не змінить, довжина серії 1 | Все обчислилося для одного числа, зсув відпрацював без помилок |
| усі елементи однакові | 1, 3 | Сума порахується правильно, а серія знайдеться на всю довжину масиву | Сума правильна, серія показала значення цього елемента і максимальну довжину |
