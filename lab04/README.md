## Відповіді на питання

1. **У скільки разів Insert(0, x) повільніший за Add(x) і чому?**
Вставка на початок працює значно повільніше. List в основі використовує динамічний масив. Метод Add(x) просто пише елемент у кінець масиву за O(1). Метод Insert(0, x) змушує зсувати всі наявні елементи в пам'яті на одну позицію праворуч, щоб звільнити місце для нового елемента на нульовому індексі, що займає багато часу (складність O(n)).

2. **Чому заздалегідь задана місткість (Capacity) дає виграш, хоч кількість Add та сама?**
Якщо місткість не задана, масив постійно переповнюється під час додавання. Список змушений виділяти новий, більший масив у пам'яті й копіювати туди всі старі елементи. Завдяки new List<int>(100000) потрібний об'єм пам'яті виділяється один раз, і жодних зайвих копіювань не відбувається.

3. **Чому Contains тисячу разів помітно довший за сто тисяч Add?**
Метод Add виконує прямий запис у кінець за O(1). Метод Contains для несортованого списку робить лінійний пошук від початку до кінця (O(n)). Оскільки елемента в списку немає, Contains щоразу перебирає всі 100 000 елементів. Виконання цієї перевірки 1 000 разів сумарно робить 100 мільйонів операцій порівняння.

---

## Які елементи пропустив хибний варіант у Завданні 2?
Хибний варіант видалення через цикл від початку пропускає від'ємні елементи, які йдуть у списку підряд один за одним. 
Коли ми робимо RemoveAt(i), наступний елемент з індексу i+1 відразу зміщується ліворуч на індекс i. Оскільки цикл робить i++, цей зміщений елемент просто перескакує і не перевіряється програмою.
